# Demos

Screenshots of the projects in this portfolio, captured by building and running each one from its own repository on Linux (Ubuntu 24.04, gcc, OpenJDK). Nothing here is mocked up: terminal images are the programs' real output, rendered as images, and the Stratego images are screenshots of the running Swing app.

All inputs are small made-up samples, included next to the images:

| Project | Input |
|---|---|
| Linux shell | [commands.txt](linux-shell/commands.txt), run in a folder with `main.c` and one `fruits.txt` file |
| Bus simulation | `8` students, typed at the prompt |
| Streaming Service | [phase-a-events.txt](streaming-service/phase-a-events.txt), [phase-b-events.txt](streaming-service/phase-b-events.txt) |
| Stratego | A few clicks: Play, move Blue's Yeti forward, move Red's Mage up, attack |

The shell and bus simulation were run in a terminal session set up like the course's SSH server (user `csd5061`, host `mango`, home `/home/ugrads/class21/csd5061`, the assignment folders under `~/hy345`), so the prompts match how they were originally used.

Excerpts marked `...` skip the start or middle of a long run.
